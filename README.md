# Contador de Cliques

Um projeto simples feito com HTML, CSS e JavaScript para praticar o fluxo de trabalho do Git e GitHub.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Clique em **+1 clique** para aumentar o contador ou em **Zerar** para reiniciar.

## Tecnologias

- HTML: estrutura da página.
- CSS: aparência e layout.
- JavaScript: funcionamento dos botões e do contador.

## Ideia da atividade

A versão inicial fica na branch `main`. Na branch `melhorias`, podemos melhorar o projeto, por exemplo, adicionando um botão para diminuir o contador e um recorde de cliques.
